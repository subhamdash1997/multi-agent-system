# TripMate AI — React UI

A React/Vite implementation of the TripMate AI travel planner landing page shown in the reference image.

## Included

- Dark navy/purple AI-style background
- Responsive hero section
- TripMate AI badge
- "Plan Your Perfect Trip with AI" heading
- Travel prompt textarea
- Online status pill
- Generate Plan button
- Japan / Dubai / Thailand / Global Flights quick chips
- Small travel/search controls
- Responsive mobile layout
- No face/webcam/video overlay from the reference image

## Run locally

Requirements:
- Node.js 18+

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The project is intentionally frontend-only. The Generate Plan button is a UI interaction and can later be connected to your FastAPI/LangGraph backend.
